# Tasks

This extension connects Tasks (tasks.vinguler.com) through its MCP server `tasks`. Before working
with Tasks, read and follow `skills/tasks-workflow/SKILL.md` in this extension; to end a session
use `skills/wrap-up/SKILL.md`, to resume one `skills/continue/SKILL.md`.

Not connected yet: run `/mcp auth tasks`, log in or sign up in the browser, pick the workspace and
Allow. The usage hook is Claude Code only.
